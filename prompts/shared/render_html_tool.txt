Verify HTML/JS output by rendering it in a real headless browser. Use this AFTER execute_code produced a SANDBOX_HTML_URL (from writing "output.html") to check that the page actually works: the tool loads the page in headless Chrome, collects all browser console messages (including uncaught JavaScript errors with line numbers) and takes a screenshot that is automatically displayed in the chat. Pass the exact SANDBOX_HTML_URL from the execute_code result as html_url. Optional wait_ms (default 5000) fast-forwards timers/animations before the screenshot — increase it for pages that build up over time. Typical workflow: write output.html → render_html → if console shows errors, fix the code and repeat. An empty console means no JS errors were detected.
