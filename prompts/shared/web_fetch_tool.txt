Fetch and read the content of a specific URL. Use this when you know the exact URL you need (e.g. a specific page on bibleserver.com, a documentation page, a Wikipedia article). This is more precise than web_search when you already know WHERE the information is. You can construct URLs from known patterns (e.g. bibleserver.com/HFA/Psalm139). If a fetch fails, try simplifying the URL (remove verse ranges, query parameters, special characters). Fetch the base page first to learn the site's URL pattern. IMPORTANT: Before calling this tool, briefly tell the user what you are about to look up.
