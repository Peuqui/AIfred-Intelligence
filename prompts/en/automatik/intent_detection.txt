**2. Addressee (who should respond):**
Available agents (for context only — DO NOT route based on topic):
{agent_list}

**Set an addressee ONLY when the user EXPLICITLY addresses an agent by name.**
Topic-based / expertise routing is DISABLED — the user picks their agent
manually via UI button (browser) or wake-word (Puck). Do not infer based
on the query subject (math → Codi, philosophy → Sokrates etc.).

Rules for name detection:
- Speaking TO someone = addressee ("Hey Sokrates, ...", "Codi, hilf mir").
- Speaking ABOUT someone = NOT addressee ("Was meint Sokrates?" → leer).
- Naming a mode, a topic or the participants of a debate is NOT addressing
  ("Start a tribunal about X", "Starte ein Symposion mit Codi und HAL" → leer).
- Ignore grammar/spelling — focus on semantic intent.
- **Phonetic variations matter**: STT transcripts are noisy (Whisper, Vosk).
  Each agent's entry above lists ``aliases`` if present — these are common
  STT misspellings. Match user input against name AND aliases. If unsure
  whether a phonetic variant refers to an agent: prefer matching it.

If no explicit name address → leave it empty (""). The server falls back to
the active agent (UI selection / last sticky).

**3. Mode Switch (detect if the user wants to change AIfred's settings):**

The user may request a configuration change. Detect these and encode them as
comma-separated key=value pairs:

- `multi=standard`   → single agent responds (default)
- `multi=tribunal`   → all three agents debate (AIfred + Sokrates + Salomo)
- `multi=symposion`  → multiple selected agents discuss
- `multi=critical_review` → Sokrates critically reviews AIfred's answer
- `multi=code_review` → a reviewer reads and tests the code the answering agent wrote, the author fixes the findings, until the review passes
- `multi=auto_consensus`  → agents debate until consensus
- `agent=<id>`       → set a specific agent as responder. **MUST be the
  lowercase agent ID** from the list in section 2 above (e.g. `hal`,
  `pater`, `codine`) — NEVER the display name (NOT `HAL 9000`, NOT `Pater Tuck`).
- `symposion_agents=<id>,<id>,...` → ad-hoc participant list when the user
  names WHO should join the symposion. Lowercase agent IDs, comma-separated.
  Only together with `multi=symposion`; omit when no participants are named.

Examples of mode switch detection (works in ALL languages):
- "Start tribunal"                          → multi=tribunal
- "Démarre le tribunal"                     → multi=tribunal
- "Inicia el tribunal"                      → multi=tribunal
- "Solo Sokrates debería responder"         → multi=standard,agent=sokrates
- "Ich will mit Sokrates weiter reden"      → agent=sokrates
- "I want to keep talking to HAL"           → agent=hal      (lowercase id, NOT "HAL 9000")
- "Schalt um auf HAL 9000"                  → agent=hal      (lowercase id, NOT "hal 9000")
- "Bleib bei Pater Tuck"                    → agent=pater    (lowercase id, NOT "Pater Tuck")
- "Starte Symposion mit Codi, HAL und Rabbi" → multi=symposion,symposion_agents=codi,hal,rabbi
- "Start a symposion with Sokrates and Pater Tuck" → multi=symposion,symposion_agents=sokrates,pater
- "Starte Symposion"                        → multi=symposion (no participants named)
- "Wie geht's?"                             → "" (no mode switch)

Detecting persistent agent switch:
- If the user says they want to CONTINUE talking to / discussing with / stay with a specific agent,
  that is an `agent=<id>` switch (persistent). This is different from a one-time addressee (field 2).
- One-time: "Sokrates, erkläre mir X" → Addressee only, no mode switch
- Persistent: "Ich möchte mit Sokrates weiter diskutieren" → agent=sokrates mode switch

Only fill this field if the user EXPLICITLY requests a mode/configuration change.
Questions about modes ("What is Tribunal mode?") are NOT mode switches — leave it "".
Addressing an agent is NOT a mode switch: `multi=standard` only when the user asks for the
standard mode or to leave a debate ("Codi, erklär mir X" → "").

**4. Pure Command Flag:**

Classify whether the message is a PURE mode-switch command (no actual question
or content alongside) or whether it ALSO contains an inhaltliche question/request.

- TRUE  → message is ONLY a mode/configuration command, nothing else
- FALSE → message contains a question or request beyond the mode command (or
          there is no mode command at all)

Only the mode and the participants belong to the command. Anything else the user asks for — a
topic to discuss, a task, a question — is content → FALSE, even in the same sentence as the
command ("Start a tribunal about whether X", "Switch to critical review and check my essay").

DO NOT extract or rewrite the user's text — this field is a classification only,
the original user message is always preserved verbatim.

Examples:
- "Start tribunal"                                  → TRUE
- "Bleib bei Pater Tuck"                            → TRUE
- "Starte ein Symposion mit Codi und HAL"           → TRUE (the participants belong to the command)
- "Start tribunal and discuss climate change"       → FALSE (has question)
- "Wie geht's?"                                     → FALSE (no mode command)
- "Hey Sokrates, kritisiere das"                    → FALSE (no mode command)

**Output format - STRICT SCHEMA:**

Return EXACTLY one JSON object with these four keys, nothing else:
{{"language": "DE", "addressee": "", "mode_switch": "", "pure_command": false}}

Rules:
- language: "DE" or "EN"
- addressee: one of the agent IDs listed in section 2 (lowercase), or "" when nobody is addressed
- mode_switch: the comma-separated key=value pairs of section 3, or "" when there is no switch
- pure_command: true or false; MUST be false when mode_switch is ""
- No explanations, no extra text, no code fences: ONLY the JSON object

Examples of complete output:
- "Wie geht's?"                      → {{"language": "DE", "addressee": "", "mode_switch": "", "pure_command": false}}
- "Start tribunal"                   → {{"language": "EN", "addressee": "", "mode_switch": "multi=tribunal", "pure_command": true}}
- "Starte Tribunal und diskutiert X" → {{"language": "DE", "addressee": "", "mode_switch": "multi=tribunal", "pure_command": false}}
- "Hey Sokrates, kritisiere das"     → {{"language": "DE", "addressee": "sokrates", "mode_switch": "", "pure_command": false}}
