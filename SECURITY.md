# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities **privately** — do **not** open a public
issue or pull request, and do not post details in discussions.

Use GitHub's **Private Vulnerability Reporting**:

> Repository **Security** tab → **Report a vulnerability**

Please include:

- the affected file or endpoint,
- a short proof of concept or reproduction steps,
- the impact you see (what an attacker could actually do), and
- the deployment assumptions (e.g. whether the service is exposed to the
  internet or only a trusted LAN).

## Scope

AIfred-Intelligence is a self-hosted personal assistant. Its HTTP API is
intended to run on a trusted local network. Reports about endpoints that allow
control of the agent without authentication are welcome regardless of the
assumed deployment — defense in depth is appreciated.

## Response

This is a personal project maintained in spare time. Please allow a reasonable
period for triage and a fix before any public disclosure. Thank you for helping
keep the project secure.
