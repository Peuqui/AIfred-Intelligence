Destructive mailbox actions via IMAP: delete (by msg_id, moves the email to Trash), move (msg_id + target_folder), create_folder (folder_name), index_attachment (msg_id + attachment: puts an attachment into the document index for search_documents). Works ONLY from the web UI where the user is present: a request from an external channel (email, Telegram, Discord, …) cannot use it — do not attempt it there, tell the user it must be done in the web UI. Always confirm the exact target (msg_id / folder) with the user before deleting or moving, and never claim success without a tool_result.
