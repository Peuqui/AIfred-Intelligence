Read the user's private mailbox. Nothing in it can be changed: actions are check (list recent mails, unread=true lists only the unread ones), read (full email by msg_id, several separated by commas), attachment (an attachment: PDF, Office, text and calendar invitations are read as text, scans and images are described for you), index_attachment (puts an attachment into the document index for search_documents) and search (finds mails holding all given words, in subject, sender or text, across every folder unless folder is given; a hit names its folder, pass that folder to read it; the mail server matches whole words only, so 'Heizöl' does not find 'Heizölrechnung': try the word forms a mail may use). Mails stay unread and the mailbox stays exactly as it was.
Long mails and attachments are read by lines like a file: the answer names the lines it holds, go on with line_start.
Lists show date, sender and subject, no content: to know what mails say, read them, several at once in one call. In lists, 📩 marks an unread mail and 📧 a read one.

This is NOT the mailbox of the email tool, which is AIfred's own: a msg_id from one tool means nothing in the other. Nothing can be sent, answered, deleted, moved or marked from here; if the user asks for that, say so.

CRITICAL: looking into the mailbox needs a tool call. NEVER describe a mail unless a tool_result shows it.
