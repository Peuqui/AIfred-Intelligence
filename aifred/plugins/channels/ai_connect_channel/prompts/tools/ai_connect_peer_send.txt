Send a message to one peer of the AI-Connect network (another assistant, e.g. a coding session). Use this ONLY when the user asks for it or the peer's status line does not answer the question. A message wakes the peer and interrupts what it is doing, so check ai_connect_peer_list first and do not disturb a peer that is busy with something urgent. Never send to several peers at once without the user's explicit request. The answer arrives later as a separate incoming message, do not wait for it.
