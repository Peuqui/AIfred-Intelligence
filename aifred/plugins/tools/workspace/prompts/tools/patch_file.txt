Replace one exact text passage in a text file in the documents directory. For targeted edits and small corrections ALWAYS use this instead of write_file — write_file with partial content would destroy the file. read_file first. The old text must occur exactly once (include surrounding lines to make it unique); replace_all=true deliberately replaces every occurrence (e.g. renaming a variable). Fails safely if the old text is missing or ambiguous, never truncates the file. HTML files are re-embedded in the chat after the patch.
