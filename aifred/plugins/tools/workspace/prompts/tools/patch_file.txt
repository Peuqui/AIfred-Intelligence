Replace one exact text passage in a text file in the documents directory. Preferred over write_file for targeted edits: pass the exact old text (must occur exactly once — include surrounding lines to make it unique) and the replacement. Fails safely if the old text is missing or ambiguous, never truncates the file. Set replace_all=true to deliberately replace every occurrence (e.g. renaming a variable). HTML files are automatically re-embedded in the chat after the patch.
