Search indexed documents by meaning and by exact words at once, across every indexed passage: names, numbers and parts of words are found as well as topics in other words. Only finds indexed documents: uploads to the documents directory are indexed by themselves, what agents write only through index_document. For one specific file (even a freshly uploaded one) use read_file instead; to search across many documents check list_indexed (or list_files) first, then search with several queries. The folder parameter restricts the search and INCLUDES all nested sub-folders (folder='bibel' covers everything under bibel/); list_indexed shows which folders have content. Omitting folder searches all documents except the Bible and Judaica corpora, which are only searched with folder='bibel' or folder='judaica'. A filename like nextcloud_files:/reports/x.pdf comes from a further source, not the local folder: read_file does not reach it, so work from the returned passages (folder='nextcloud_files:' covers that whole source). total_hits counts everything related, strong and weak, so a high number says nothing about the topic: what matters comes first. Each result carries a relevance label: 'high' / 'medium' by closeness in meaning (a hit found by its exact words may be 'medium'), 'context' for the neighbor chunks around each hit (the full surrounding passage). Results are spread across files instead of many near-duplicates from one document. PAGINATION: only when the response contains a next_page_hint — call again with the SAME query and page=2, page=3, ... (never reformulate into synonyms: they return overlapping passages). A pagination_note instead means STOP — deeper pages only hold weaker matches.
