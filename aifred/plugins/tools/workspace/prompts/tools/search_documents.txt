Search indexed documents semantically. Only finds indexed documents (index buttons in the Documents dialog or index_document) — uploading alone does NOT index. For one specific file (even a freshly uploaded one) use read_file instead; to search across many documents check list_indexed (or list_files) first, then search with several queries. The folder parameter restricts the search and INCLUDES all nested sub-folders (folder='bibel' covers everything under bibel/); list_indexed shows which folders have content. Omitting folder searches the WHOLE store (cross-corpus) — only when you genuinely don't know which corpus is relevant. Each result carries a relevance label: 'high' / 'medium' for similarity hits, 'context' for the neighbor chunks around each hit (the full surrounding passage). Results are spread across files instead of many near-duplicates from one document. PAGINATION: only when the response contains a next_page_hint — call again with the SAME query and page=2, page=3, ... (never reformulate into synonyms: they land in the same vector region and return overlapping chunks). A pagination_note instead means STOP — deeper pages only hold weaker matches.
