Move a file or folder to another place in the documents directory (rename across folders, server-side). Target may be a new path or an existing folder (the source keeps its name). Refuses to overwrite unless overwrite=true. Moved files stay searchable (ChromaDB index metadata is updated); for moved FOLDERS the contained files' index entries become stale — check list_orphaned and re-index if needed. Prefer this over delete+recreate when organizing or cleaning up the workspace.
