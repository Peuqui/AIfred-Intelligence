Read a file from the documents directory — also files that are not indexed. For PDFs, specify pages (e.g. '1-5'). Office documents (DOCX, XLSX, PPTX, ODT, ODS, ODP) come back as extracted text, tables as Markdown. For text files and Office documents, specify line_start/line_end to read a portion. IMPORTANT: For large files (>100 KB), ALWAYS use line_start/line_end to read in chunks!
