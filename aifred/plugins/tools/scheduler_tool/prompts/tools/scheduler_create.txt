Create a scheduled job. AIfred will execute the message at the scheduled time and deliver the result via the specified mode. Schedule types: 'cron' (e.g. '0 8 * * *' = daily 8am), 'interval' (seconds, e.g. '3600' = every hour), 'once' (ISO timestamp, e.g. '2026-03-30T10:00:00'). Delivery modes: 'review' (default — result shows in the UI), 'announce' (send to a channel; on freeecho2 it is read out loud in the rooms), 'webhook' (HTTP POST). A job runs the model first, which takes minutes if it is not loaded: for an exact time, as with an alarm, use fixed_text, which needs no model; a job that has to think must start earlier. In a run the agent may use every send tool except the one of its own delivery channel, but only if the message asks for it.
