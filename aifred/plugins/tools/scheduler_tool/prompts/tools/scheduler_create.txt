Create a scheduled job. AIfred will execute the message at the scheduled time and deliver the result via the specified mode. Schedule types: 'cron' (e.g. '0 8 * * *' = daily 8am), 'interval' (seconds, e.g. '3600' = every hour), 'once' (ISO timestamp, e.g. '2026-03-30T10:00:00'). Delivery modes: 'log' (default), 'announce' (send to channel), 'review' (show in UI), 'webhook' (HTTP POST).
