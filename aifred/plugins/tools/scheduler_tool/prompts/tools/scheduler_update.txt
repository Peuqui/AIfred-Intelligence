Change a scheduled job in place by its ID (keeps ID, run history and last run). Pass only the fields to change; everything left out stays as it is. 'message' replaces the stored prompt completely, so read the current text with scheduler_list first and pass the full new text. Changing schedule_type needs a matching schedule_expr. 'enabled' switches the job on or off. Use this instead of delete + create. 'end_date' sets or moves the end of a cron or interval job (empty string = no end); a job that ran to its end is off and needs a later end_date and then enabled=true.
