Change a scheduled job in place by its ID (keeps ID, run history and last run). Pass only the fields to change; everything left out stays as it is. 'message' replaces the stored prompt completely, so read the current text with horarium_list first and pass the full new text. Changing schedule_type needs a matching schedule_expr. 'enabled' switches the job on or off. Use this instead of delete + create. 'end_date' sets or moves the end of a cron or interval job (empty string = no end); a job that ran to its end is off and needs a later end_date and then enabled=true. The plan of a job: 'frame' and 'columns' replace what the job has ('columns' empty list = no columns); 'part_add' adds one part (its id must not exist), 'part_update' replaces the part of the same id completely (the id must exist), 'part_remove' removes the part of that id (a string). After the changes the whole plan is checked, and nothing is saved when it is wrong. From the run of a job itself, the job's own record cannot be changed: propose the change in the report.
