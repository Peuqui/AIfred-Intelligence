Get system status: CPU load, RAM usage, GPU VRAM and temperature, disk space, uptime, the loaded language model, and the state of speech recognition (STT) and speech output (TTS). Model, STT and TTS entries carry remaining_s: seconds until that service unloads itself for being idle (null = it stays loaded); for a model, exact=false means an upper bound. Use components parameter to query specific parts (e.g. 'gpu', 'ram,cpu', 'model,stt,tts') or 'all' for everything.
