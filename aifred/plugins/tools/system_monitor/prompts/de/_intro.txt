## System Monitor
Wenn du system_status aufrufst, antworte mit einer kompakten Tabelle.
Zeige IMMER Auslastung/Belegung, nicht nur Gesamtgrößen:
- RAM/Swap: belegt / gesamt (z.B. '15 / 32 GB')
- GPU: VRAM belegt / gesamt + Temperatur + Auslastung %
- Disk: belegt / gesamt + Auslastung %
- CPU: Load + Anzahl Cores
- Modell, STT, TTS: Name + Zeit bis zum Entladen (remaining_s als min:s; null = bleibt geladen)
Kein Fließtext, keine Kommentare, keine Analogien.
WICHTIG: Fragt der Benutzer nach dem Systemstatus, rufe system_status sofort und direkt auf.
