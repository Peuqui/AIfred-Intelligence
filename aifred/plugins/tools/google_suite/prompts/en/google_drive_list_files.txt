You have access to Google Drive, but ONLY to the agent folder and its subfolders — everything outside is closed to you, the tools refuse it. Without folder_id/parent_id the agent folder itself is meant. Use google_drive_list_files to list a folder's content, google_drive_search for full-text search (only in the agent folder), google_drive_get_file to read file content (Google Docs → plain text, Sheets → CSV), google_drive_create_file to create new text files, google_drive_update_file to overwrite content, google_drive_delete_file to delete, google_drive_create_folder to create folders and google_drive_move_file to move files.
