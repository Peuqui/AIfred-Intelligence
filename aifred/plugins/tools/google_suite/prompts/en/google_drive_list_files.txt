You have access to Google Drive. Use google_drive_list_files to list files (optionally with folder_id), google_drive_search for full-text search, google_drive_get_file to read file content (Google Docs → plain text, Sheets → CSV), google_drive_create_file to create new text files, google_drive_update_file to overwrite content, google_drive_delete_file to delete, google_drive_create_folder to create folders and google_drive_move_file to move files.
