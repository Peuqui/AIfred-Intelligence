Run a large task as a plan of independent parts. Each part is worked on by its own sub-agent (fresh context, its own tools, one after the other) that reports a status with a finding and a source for every position of its part; you receive all entries of all parts as this tool's result, followed by a line of how many positions were checked and which were not. It sees neither this conversation nor your memory, so "frame" and every part's "task" must be complete. Use it when the task falls into several independent groups, each of which is a piece of work for one agent (e.g. checking prices of many products in several shops). Not for small tasks: answer them yourself or hand them to delegate_task. A long run takes minutes. The same plan (frame, parts, columns) can afterwards be stored unchanged as a recurring job with horarium_create, if that tool is available.
