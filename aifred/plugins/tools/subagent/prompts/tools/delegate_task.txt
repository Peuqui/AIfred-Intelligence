Delegate a self-contained sub-task to a sub-agent: a fresh model run with its own context window, its own tools and its own tool loop. The sub-agent sees neither this conversation nor your memory, so "task" must contain everything it needs (facts, file names, constraints, what has already been tried). You receive only its final report as this tool's result (never write that report yourself, wait for the tool result); the user sees the full transcript in the chat. Use it to keep your own context small: long research, reading and comparing several documents, writing and testing code in the workspace, or any multi-step job whose intermediate steps you do not need to see. Do not use it for questions you can answer directly or for tasks that need the conversation as context. The sub-agent cannot send messages or delete files unless the plugin settings allow it, and it cannot ask questions back.
