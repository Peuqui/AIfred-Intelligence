Delegate a self-contained sub-task to a sub-agent: a fresh model run with its own context window, tools and tool loop; you receive only its final report as this tool's result. It sees neither this conversation nor your memory and cannot ask back, so "task" must contain everything it needs. Use it to keep your own context small — long research, reading and comparing several documents, writing and testing code, multi-step jobs whose intermediate steps you do not need to see. Not for questions you can answer directly or tasks that need the conversation as context.
