Play an audio item from the BEGINNING (default). The 'item' parameter is a label-prefixed identifier (e.g. 'hoerbuecher/Tolkien_HdR.mp3' for a file in the 'hoerbuecher' source, or just 'swr3' for an HTTP stream). Use audio_list() to see available labels and items. Resume from saved position: set restart=false (or use the audio_resume tool which is dedicated for that). Use audio_play when the user says 'play X', 'spiele X', 'starte X' (start fresh). Use audio_resume / restart=false when the user says 'continue X', 'spiele X weiter', 'mach X weiter', 'setze X fort'. The 'target' parameter selects the output sink ('local', 'browser:<id>', 'freeecho2:<room>'); when omitted, audio is routed to the channel where the request came from.
