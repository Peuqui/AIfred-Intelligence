Read ONE EPIM entry with full details: a note (including all tabs with their content), a task/event or a contact. You MUST call this tool when the user wants the CONTENT of a note or details of a specific entry — epim_search only returns titles/metadata for notes, NOT their content. Flow: first epim_search to find the entry, then epim_get with the ID from the search result. Password entries can NOT be read through this tool.
