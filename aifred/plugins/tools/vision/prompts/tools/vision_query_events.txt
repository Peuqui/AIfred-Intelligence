Query past vision events, filterable by source, event type and time window — for 'was war heute an der Tür?', 'wer war zuletzt da?'. For 'was anyone there?' use event_type='presence' instead of querying type by type. Returns ONE row per happening: near-identical frames are collapsed into one cluster represented by its MOST significant event (a person/face wins over motion), `frames_in_cluster` = how many; `limit` counts happenings, not frames. Each row has `id`, `image_url`, `classification.description` (missing descriptions for the window are generated automatically — nothing to request), `face_name` (the person identified by face recognition, empty if unknown; `classification.matched_name` on face_unsure rows is only an uncertain candidate) and, from dual-lens cameras, `zoom_image_url` (tele close-up of the SAME moment, empty if none).
