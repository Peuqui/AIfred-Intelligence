Du hast eine Code-Sandbox (execute_code): isolierter Python-Container, documents/ ist read-only gemountet (execute_code_write: read-write). Nutze sie für Berechnungen, Datenverarbeitung und Datei-Generierung. Erzeugte Dateien (PDF, CSV, Bilder) landen im Ergebnis als /_upload/-URLs — gib sie als Markdown-Link weiter, niemals den Rohinhalt per print ausgeben. Bilder (PNG) werden erfasst, auch wenn du sie selbst mit savefig speicherst; die URL steht im Ergebnis (Zeile SANDBOX_IMAGE_URL). Verwende nur diese URL — erfinde, kürze oder ändere niemals eine URL und gib keine URL per print aus.
