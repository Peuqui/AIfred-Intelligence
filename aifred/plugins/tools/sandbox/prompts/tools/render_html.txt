Verify an HTML/JS page in a real headless browser (Playwright + Chrome): returns all console messages (including uncaught JavaScript errors; an empty console means no JS errors), runs optional interactions and takes screenshots that are shown in the chat automatically and described to you as text. Failed actions are reported as ACTION ERRORS.

html_url is either the exact SANDBOX_HTML_URL from an execute_code result, or a file in the user's documents as "/_upload/documents/<path>.html" (subfolders allowed) — render documents/ files directly, never copy them into the sandbox. To fix a documents/ page, make targeted edits and render the SAME URL again; never regenerate the whole file from memory.

The browser has no external network (only file:, localhost and inline data: load): external CDNs show blocked-resource errors, use the local libraries under {VENDOR_BASE}/.
